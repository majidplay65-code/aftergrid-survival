## ۰. حکم یک‌خطی

**Aftergrid الان یک پروتوتایپ عمودیِ قابل‌بازی است، نه یک بازی تمام.**  
اسکلت معماری (داده / رفتار / ارتباط) درست است. حلقهٔ بقا، تهدید، نویز، اینونتوری و مرگ روی StateMachine سوار شده. چیزی که کم است **فشار معنایی** است: تاریکی واقعی، فضای داخلی، خط دید، دلیل حرکت، و یک شرط برد شبانه.

تخمین صداقت‌آمیز:

| لایه | درصد واقعی | توضیح کوتاه |
| --- | ---: | --- |
| معماری هسته (EventBus / Resource / SM) | **۹۰٪** | قرارداد پایدار است؛ چند نشتی جزئی مانده |
| کنترلر بازیکن | **۸۰٪** | Idle→Dead کامل؛ حس وزن/انیمیشن نیست |
| حلقهٔ بقا (گرسنگی/تشنگی/جان/سیو) | **۷۵٪** | دو مسیر مصرف (دنیا vs کیف) هنوز موازی‌اند |
| تهدید / AI | **۵۵٪** | سه واریانت + نویز؛ دید از دیوار می‌گذرد |
| جهان | **۵۰٪** | بلوک شهری + حیاط؛ ساختمان‌ها جعبهٔ توپرند |
| پیشرفت / هدف جلسه | **۱۵٪** | شرط برد وجود ندارد |
| تولید (انیمیشن، صدا غنی، UX) | **۲۵٪** | منو/SFX پروسیجرال/export هست |
| **محصول قابل‌انتشار به‌عنوان بازی** | **~۴۰٪** | ۵ دقیقه راه می‌روی؛ «چرا برگردم» ضعیف است |

## ۱. قانون‌های معماری که تا اینجا قفل شده‌اند

این‌ها ستون‌اند. فازهای بعدی حق ندارند بشکنندشان.

1. **داده = `Resource`** (`PlayerStats`, `SaveData`, `ItemData`, `RecipeData`, `ItemCatalog`, `Inventory`).
2. **رفتار = Node StateMachine** (`core/state_machine/`) برای بازیکن و دشمن؛ یک الگو، دو موجود.
3. **ارتباط بین‌سیستمی = فقط `EventBus`**. بدون `get_node("../../OtherSystem")`.
4. **GDScript کاملاً typed.** `gdparse` + CI گارد `SCRIPT ERROR|ERROR:|WARNING:`.
5. **نویز event-driven است.** چک فاصله فقط داخل هندلر سیگنال؛ پارامتر `noise_position` نه `position`.
6. **سلاح گرم نیست.** منبع تهدید = دید Area3D + شنیدن نویز کنش‌های موجود (قدم، دویدن، ساخت، ضربه، پرش).
7. **هر لایه یک commit + push + تأیید `gh api` SHA.** Merge فقط با جملهٔ مالک.

Autoloadهای زنده (ترتیب لود):

`EventBus` → `GameState` → `SceneManager` → `SaveManager` → `InventoryManager` → `CraftingSystem` → `AudioManager`

## ۲. حسابرسی فازبه‌فاز (۰ → ۱۷)

ریپو، `project.godot`، پوشه‌بندی استاندارد Godot، `.gitignore`، CI.  
نام کاری **Aftergrid** عمداً قفل نشده. نسخهٔ دوبعدی موقت حذف و روی baseline سه‌بعدی ریست شد.

حفره: برند/آیکون نهایی لازم نیست تا حلقه ثابت شود.

### فاز ۱ — Core Systems | ~۹۵٪

`EventBus`, `GameState`, `SceneManager`, `SaveManager` + `SaveData` Resource، `State`/`StateMachine`.  
ورود اولیهٔ SM عمداً `call_deferred` است تا `@onready` والد null نباشد — درس فاز ۵.

حفره: تأیید نهایی کاربر «ببند و باز کن از همان نقطه» در README هنوز خالی است.  
مرگ اکنون سیو را قطع می‌کند (فاز ۱۷) ولی سیو *قبلی* سر جایش می‌ماند — برای «تلاش مجدد» خوب است.

### فاز ۴ — World Identity | ~۷۰٪ به‌عنوان هویت بصری

بلوک شهری گرگ‌ومیش: ۶ ساختمان بتنی، خیابان، خودرو سوخته، ژنراتور، تکسچر tileable، مه/SSAO/ACES.

### فاز ۵ — Threat | ~۷۰٪ سیستم / ~۴۰٪ «دشمن باهوش»

`NavigationRegion3D` + `NavigationAgent3D` + Patrol/Chase/Attack.

- فلگ carve فقط در bake اثر دارد؛ navmesh این پروژه دستی است → carve داخل `polygons` نوشته شد.

حفرهٔ طراحی: Area3D کروی **از دیوار رد می‌شود**. خزیدن و ساختمان تا وقتی LOS نباشد، استیلث واقعی نمی‌سازند.

شش لایهٔ عمدی: ItemData → Inventory → .tres واقعی → Crafting اتمیک → سیم‌کشی EventBus/سیو → UI تب.

کاتالوگ: ۴ آیتم (قراضه/کنسرو/آب/مدکیت) + ۲ دستور (فیلتر آب، مدکیت ساده).

## ۳. نقشهٔ سیستم‌ها (آنچه واقعاً به هم وصل است)

```
[Input] → Player StateMachine
            Idle / Walk / Run / Crouch / Melee / Jump / Dead
                 │
                 ├─ PlayerStats (Resource) ──stat_changed──► EventBus ──► HUD / Audio
                 ├─ noise_emitted ──► Enemy Investigate / Chase
                 ├─ item_consumed ──► stats.drink/eat/heal
                 └─ player_died ──► HUD GameOver + DeadState + skip save

[E RayCast] → Interactable
                 ├─ ItemPickup (مصرف فوری یا item_picked_up)
                 └─ PowerSwitch → light + generator_charge_requested → battery

[Tab] InventoryUI → use_item / CraftingSystem.craft → inventory_changed

Enemy StateMachine: Patrol → (sight) Chase → (range) Attack
                    Patrol → (noise) Investigate
                    HP 0 → enemy_died → LootSpawner scrap

SaveController ↔ SaveData Resource ↔ disk
```

ورودی‌های زنده:

| اکشن | کلید |
| --- | --- |
| حرکت | WASD |
| دویدن | Shift |
| خزیدن | C |
| پرش | Space |
| تعامل | E |
| چراغ‌قوه | F |
| اینونتوری | Tab |
| ضربه | کلیک چپ / V |
| سیو / لود | F5 / F8 |
| توقف | ESC |

دشمنان سطح تست: Enemy1 Shambler تقاطع، Enemy2 Stalker جنوب‌شرق، Enemy3 Brute جنوب‌غرب، Enemy4 Shambler حیاط. اسپاون بازیکن `(0,1,7)`؛ سیو تست `(26,1,0)`.

تست headless: ۱۸ فایل در `tests/` — CI همه را با گارد خطا اجرا می‌کند.

## ۴. بدهی فنی که فاز بعد باید دورش بچرخد، نه انکارش

1. **دید از دیوار** — Area3D بدون ray. استیلث دروغ است.
2. **ساختمان توپر** — هویت بصری بدون فضای داخلی.
3. **دو حلقهٔ مصرف** — دنیا فوری، کیف دکمه‌ای.
4. **جهان همیشه گرگ‌ومیش** — باتری بی‌معنا می‌ماند.
5. **بدون شرط برد جلسه** — مرگ هست، «شب را تمام کردی» نیست.
6. **Chase بدون حافظه** — خروج از کره = فراموشی آنی؛ ورود = قفل.
7. **پرش بدون هزینهٔ ارتفاع** — JumpState آماده است، پیامد نیست.
8. **ساخت آنی** — دستور هست، زمان/نویز کمپ نیست (جز یک emit ساخت).
9. **لوت تخت** — فقط scrap.
10. **تست دستی ۷–۱۷ باز** — کد روی PR است؛ مالک هنوز در ادیتور تأیید نکرده.

این‌ها تصادفی نیستند. همه به یک جمله برمی‌گردند:

> بازیکن باید **بترسد که دیده شود، مجبور باشد داخل برود، نور را بشمارد، و یک شب را تمام کند.**

## ۵. ده فاز بعدی (۱۸ → ۲۷) — برنامهٔ مالک

فرض مالک: Aftergrid بازی **بقا-استیلث شهری بعد از خاموشی شبکه** است، نه شوتر، نه اوپن‌ورلد بی‌هدف.  
هر فاز یک لایه است، یک commit، تست headless، بدون سلاح گرم، بدون پرش از روی بدهی بالا.

معیار عبور همان DoD قدیمی: *۵ دقیقه بازی کنی و بگویی ادامه بده.*

### فاز ۱۸ — Line of Sight (چشم واقعی تهدید)  | اولویت P0

**چرا الان:** خزیدن، ساختمان، نویز — هر سه تا وقتی دشمن از بتن «می‌بیند» تزئین‌اند.

- روی `body_entered` SightArea یک `PhysicsRayQueryParameters3D` از چشم دشمن به سینهٔ بازیکن.
- اگر collider دیوار/جهان بود → Chase نشود (یا Investigate کوتاه).
- پارامتر `noise_position` دست نخورد؛ این لایه فقط **دید** است نه شنوایی.
- تست: بازیکن پشت ObstacleB1، داخل شعاع دید، ray بسته → Chase نشود؛ از گوشه بیرون بیاید → Chase شود.

وابستگی: هیچ فاز جدیدی لازم نیست. قفل معماری را تقویت می‌کند.

### فاز ۱۹ — در و فضای داخلی  | P0

**چرا:** جهان جعبه است. استیلث و لوت جای «پشت دیوار» می‌خواهند.

- ۲–۳ ساختمان با دهانهٔ در (نه Boolean پیچیده: دهانه روی collision + اتاق داخلی ساده).
- `Door` از `Interactable` (E باز/بسته؛ نویز کم).
- navmesh همان ابزار `regen_navmesh.py` با سلول در — اعداد رأس/مثلث تست save_load و world_expansion باید آگاهانه به‌روز شوند.
- یک اتاق = ۲ آیتم + تاریکی نسبی.

اسپاون `(0,1,7)` و `(26,1,0)` توخالی بمانند.

### فاز ۲۰ — یک کیف، یک حقیقت  | P0 حلقهٔ بقا

**چرا:** دو سیستم مصرف = بازیکن نمی‌فهمد قوانین چیست.

- `is_consumable_on_pickup = false` برای آب/غذا/دارو در جهان.
- E = برداشتن به اینونتوری؛ مصرف فقط Tab → مصرف.
- `inventory_wiring_test` را **عمداً** با تعداد چک جدید به‌روز کن (الان انتظار «آب به کیف نمی‌رود» دارد — این لایه همان قرارداد را عوض می‌کند).
- ظرفیت کیف محدود (مثلاً ۱۲ اسلات شمارشی از stack) تا تصمیم معنا داشته باشد.

بدون این فاز، شب و گرسنگی فقط نوار HUDاند.

### فاز ۲۱ — چرخهٔ شب و دید محیط  | P0 فانتزی «After-grid»

**چرا:** اسم بازی خاموشی شبکه است؛ نور صحنه هنوز مهربان است.

- Resource `WorldClock` (زمان نرمال‌شده ۰..۱، نه Timer خام در Player).
- EventBus: `time_of_day_changed(normalized: float)` — HUD/Environment/Audio گوش می‌دهند.
- Environment: ambient و sun energy از روی Resource؛ نیمه شب باتری را اجباری می‌کند.
- ژنراتور = جزیرهٔ نور (از قبل Omni دارد؛ حالا معنا پیدا می‌کند).

تست: در t=نیمه‌شب `ambient_light_energy` زیر آستانه؛ باتری روشن در تاریکی.

### فاز ۲۲ — شرط برد شب  | P0 محصول

**چرا:** مرگ هست، پیروزی جلسه نیست. بدون برد، تست ۵ دقیقه بی‌هدف است.

- هدف جلسه: **تا سپیده‌دم زنده بمان** (مثلاً ۶ دقیقهٔ فشرده = یک شب پروتوتایپ).
- HUD: «شب ۱ — تا سپیده ۴۲٪».
- سپیده → `EventBus.night_survived(night_index)` → پنل «زنده ماندی» (نه Game Over).
- سیو `night_index` روی SaveData با پیش‌فرض ۱ (سیوهای قدیم نشکنند؛ save_load_test را بدون افزایش اجباری ۹۸ نگه دار مگر چک جدید جدا).

این فاز بازی را از «سندباکس سیستم» به «جلسه» تبدیل می‌کند.

### فاز ۲۳ — پناه / استراحت  | P1 فشار و رهایی

**چرا:** بعد از شب و داخل، بازیکن جای امن می‌خواهد وگرنه فقط kite می‌کند.

- Interactable `RestSpot` داخل یک اتاق (تخت/ژنراتور روشن).
- شرایط: دشمن در Sight نیست + (اختیاری) در بسته.
- استراحت: hunger/thirst کمی برمی‌گردد، زمان جلو می‌پرد، auto-save، نویز صفر.
- اگر ژنراتور خاموش باشد استراحت کوتاه‌تر/خطرناک‌تر (Investigate تصادفی — فقط از EventBus نویز ضعیف، نه spawn جادویی).

### فاز ۲۴ — حافظه و رها کردن تعقیب  | P1 AI

**چرا:** Chase دودویی است. بعد از LOS باید «چند ثانیه آخر را بگرد» نه teleport به Patrol.

- `last_seen_position` روی Enemy (داده روی موجود، نه Autoload).
- از دست دادن LOS → Investigate به آخرین نقطه، تایم‌اوت → Patrol.
- Stalker تایم‌اوت بلندتر، Brute کوتاه‌تر — data-driven مثل hearing_multiplier.

تست: دشمن Chase را می‌بیند، بازیکن پشت دیوار می‌رود، state Investigate است نه Patrol فوری.

### فاز ۲۵ — سقوط و قیمت ارتفاع  | P1 فیزیک بازیکن

**چرا:** JumpState بدون پیامد = حرکت رایگان. بقا یعنی ارتفاع هزینه دارد.

- در `JumpState`/`land_from_jump`: اگر `fall_speed` از آستانه گذشت → `stats.take_damage`.
- نویز فرود سخت‌تر (از LAND_NOISE موجود مشتق شود، ثابت جدید).
- خزیدن از لبه پرش نمی‌دهد (قبلاً قفل است).

مراقب save_load: آسیب سقوط نباید در ۱۵ فریم فیزیک نقطهٔ سیو را خراب کند — آستانه بالاتر از snap زمین.

### فاز ۲۶ — میز ساخت / زمان ساخت  | P1 اقتصاد

**چرا:** دستور آنی = قراضه دکمه است. ساخت باید مکان و نویز بخواهد.

- Interactable `WorkedSurface` نزدیک ژنراتور.
- `CraftingSystem.craft` اگر `craft_time > 0` در حالت `CraftState` بازیکن قفل کوتاه + نویز دوره‌ای (۱۰m موجود را نگه دار).
- UI: دکمه فقط وقتی نزدیک میز فعال است؛ دور از میز disabled + دلیل `too_far` روی `craft_failed`.

تست UI موجود را با چک جدید یا تست جدا گسترش بده؛ تعداد ۲۷ را بی‌خبر عوض نکن.

### فاز ۲۷ — برج رادیو / دلیل شرق  | P1 روایت مکانیکی

**چرا:** حیاط صنعتی جغرافیا است. بازیکن باید *بخواهد* از تقاطع جدا شود.

- Interactable `RadioBeacon` روی سوله/انبار شرق (فاز ۹).
- فعال‌سازی با (قراضه یا باتری یا فیلتر — یک هزینه از کاتالوگ موجود، آیتم جدید فقط اگر لازم).
- اثر: `night_survived` زودتر شمرده می‌شود / یا شب بعد Stalker کمتر اسپاون می‌شود — **بدون تفنگ**.
- این «پایان پروتوتایپ عمودی» است: شب را زنده ماندی + سیگنال زدی.

بعد از ۲۷، محصول باید این جمله را تحمل کند:

> «اولین شب را در تقاطع قایم شدم، با خزیدن از Shambler رد شدم، داخل ساختمان غذا برداشتم، باتری را در ژنراتور پر کردم، و قبل از سپیده به رادیو شرق رسیدم.»

اگر آن جمله در ادیتور دروغ باشد، فاز را تمام‌شده اعلام نکن.
